## 文档维护

README 保留简介、安装和开始使用。日常操作写入使用指南，实现状态维护在功能清单，技术机制写入当前架构；验证结果按日期记录到验收目录并更新索引。历史记录保留原结论，新结果另写记录并链接，避免把旧结果当作当前状态。
