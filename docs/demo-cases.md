# 业务案例与录屏步骤

[文档目录](README.md) · [使用指南](user-guide.md)

在“工具连接 → 案例库”选择案例、智能体和供应商，创建独立沙箱。默认停止；启动后复制概览中的任务，在智能体会话中发送。项目的 `TASK.md` 保存相同任务，产出文件保留在项目中。可以给不同案例绑定不同供应商，对比报告、用量与费用。

案例服务有三个只读工具：`case_overview` 查看数据集与字段，`read_data` 读取和筛选，`summarize_data` 按文本字段分组并计算数值字段之和。不接受 SQL、命令、任意路径或 URL。所有数据均为合成数据，服务不连接生产系统；MCP 调用和报告生成是真实执行。

建议录制流程：

1. 展示模型供应商与沙箱绑定，选择 DeepSeek Harness 的按量供应商。
2. 从案例库创建退款复盘沙箱，启动，复制任务并发送。
3. 展示会话的工具调用、分析与最后报告。通过“在访达中显示”找到项目文件夹，查看实际生成的文件，核对上表指标。
4. 打开用量、费用、运行状态与请求日志，展示该沙箱的实际数据。提前在供应商设置填好单价，否则应展示“未估价”。
5. 可创建另一个案例，绑定不同供应商；完成后停止沙箱。删除沙箱保留项目报告。

每个案例默认 200 次请求、200000 token，可在沙箱额度设置修改。创建案例不发模型请求；实际运行按供应商计费。案例只读服务不需要密钥，仍经过沙箱门卫的内部鉴权与工具名单；项目文件工具及 Agent 自带文件操作可以写入当前项目。

Codex、Claude Code 使用其原生 MCP 配置；DeepSeek Harness 使用官方 `@deepseek-ai/dsh-mcp-client`，支持远程 HTTP 与项目 filesystem。配置更新后新建会话应用。模型是否正确引用工具和结论仍需核对；合成安全通告不是实际 CVE，不能作为真实漏洞宣传。
