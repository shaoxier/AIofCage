# 终端文件栏验证

[验收记录索引](README.md)

## 改动

对应第二轮会议第 4 条和 [todo 清单](../round2/todo.md)第 4 项的最小版本：终端右侧加一个只读的项目文件栏，可以浏览、预览文本、把路径插入当前会话。“变更”标签（Git 状态与 diff）、拖入路径、编辑都没做。

1. **面板**
   - 终端标签栏右端有“项目文件”按钮，可以展开或收起。
   - 按沙箱记住展开状态；没有记录时，窗口宽度不小于 1180 像素才默认展开。
   - 面板固定宽 300 像素，窗口较窄时 260 像素。
2. **浏览**
   - 按需逐层读取，文件夹在前，再按名称排序。
   - 以“.”开头的条目默认不列，只显示“N 个隐藏项”，勾选“隐藏项”后列出。
   - 每层最多列 2000 项，多出的提示“只列出前 2000 项”。`node_modules` 这类目录只有点开时才读取。
   - 刷新方式：手动刷新；另外每轮对话结束时，自动重读已展开的文件夹和正在预览的文件。
3. **预览**
   - 只读常规文件，最多 512 KB。UTF-8 文本按纯文本显示，超出部分截掉，截断处不会切断汉字。
   - PNG、JPEG、GIF、WebP 图片按图片显示。
   - 二进制文件、过大的图片、符号链接、管道和设备文件都只显示说明，不读取内容。
4. **插入路径**
   - 每一行和预览区都有“插入路径”按钮，插入的是项目内的相对路径。
   - 对话插到输入框的光标处，前后自动补空格。
   - Shell 当作键入，不带回车；需要时加单引号，以“-”开头的加“./”。
   - 文件名含控制字符（例如换行、Ctrl+C）时不允许插入，免得终端把它当成按键。
   - 没有打开的会话时按钮不可用。另外可以复制路径。
5. **布局**：图片的粘贴和拖放只在左侧终端区域生效，文件栏里不触发。

## 安全约束

项目里的文件都由 Agent 控制，所以：

- **读取限定在项目内**
  - 宿主用 `os.OpenRoot` 打开项目目录，指向项目外的符号链接和 `..` 都会被拒绝。
  - 列目录和预览都先 `Lstat`：链接显示为链接，不进入也不读取。
  - 用非阻塞方式打开文件，打开后再确认是常规文件。即使检查之后文件被换成管道，也不会卡住应用。
- **预览一律当纯文本显示**：不渲染 HTML、Markdown 或 SVG。SVG 按文本显示，不当图片。图片用 data URL 放进 `<img>`。
- **只读**：不在宿主上运行 git，不用其他程序打开项目里的文件，没有编辑、新建、重命名和删除。
- **不写日志**：文件路径和内容不写进审计日志。

## 自动测试

- `internal/service`，测试项目里放了这些“陷阱”：
  - 指向项目外私钥文件的链接、指向项目内目录的链接、`src/up → ../../..`；
  - 管道；
  - 含 `<script>` 的 Markdown 和 SVG；
  - PNG 头、含 NUL 的二进制文件；
  - 超过 512 KB 的汉字文本；
  - 隐藏文件；
  - 2001 个条目的 `node_modules`。

  覆盖的情形：
  - 列目录的排序、隐藏项计数、链接和特殊文件的类型；
  - 超大目录在上限处截断；
  - `..`、绝对路径、反斜杠、绕出项目的链接、指向目录的链接都拒绝；
  - 预览：文本原样返回，交给页面当纯文本显示；SVG 不当图片；PNG 返回 data URL；二进制不返回内容；长文本在字符边界截断；两种链接都不跟随；管道不读取，5 秒内返回；任何越界路径都读不到项目外的内容。
- 前端：在光标处插入并补空格，Shell 引号和“-”开头的处理，控制字符检测。
- `make check`、`make test`（含竞态检查）、前端 `node --test` 都通过。

## 界面验证（模拟后端）

用内置浏览器在 1400×860 窗口下检查：

- 默认展开，列表顺序正确，显示“2 个隐藏项（以“.”开头）”；逐层展开 `src`、`src/util`。
- 含 `<script>` 和 `<img onerror>` 的 README 按纯文本显示，页面里没有生成任何 script 或 img 节点。SVG 也按文本显示。PNG 显示为图片。二进制、链接只显示说明。
- **对话**：
  - 没开会话时插入按钮不可用；
  - 开 Codex 对话后插入 `src/main.go`，输入框得到“src/main.go ”；
  - 把光标放在中间再插入 `README.md`，得到“src/main.go 和 README.md 看看”，光标停在插入内容之后。
- **Shell**：插入 `src/main.go` 发送“src/main.go ”，插入中文长文件名时加了单引号。
- **控制字符**：文件名含换行的那一行，插入按钮不可用，提示原因。
- **自动刷新**：模拟一轮对话开始和结束，结束时自动重读三个已展开的文件夹，进行中不读。
- **收起**：收起后记为 `closed`，再展开记为 `open`。
- **长文件名**：用省略号截断，悬停显示完整路径。

## 范围与限制

- **没做的部分**：
  - “变更”标签：需要在容器里运行 git，不能在宿主上运行；
  - 拖入路径；
  - 拖宽面板；
  - 在访达中显示；
  - 文件监听，目前只在每轮结束和手动刷新时更新。
- **沙箱停着且没有打开过会话时**，终端页只显示“启动沙箱”。读取本身不依赖沙箱运行，有已结束的标签时照常可以浏览。
- **列目录的上限**：每层只读前 2000 个条目，并且是在这 2000 个里排序，不是全目录排序。
- **图片预览**：只认 PNG、JPEG、GIF、WebP 的文件头，不校验整张图片；超过 512 KB 的图片不预览。
- **真实桌面应用还没试**：在真实桌面应用里点一遍（包括 xterm 的 Shell 插入）留给用户；后端逻辑由上面的单元测试在真实文件系统上覆盖。
