# 供应商模型列表验证

[验收记录索引](README.md)

## 改动

对应第二轮会议第 5 条和 [todo 清单](../round2/todo.md)第 5 项。

1. **公共的取模型函数**（`internal/service/models.go`）：
   - 按协议请求 `/models`：OpenAI 兼容接口是 `<地址>/models`；Anthropic 是 `/v1/models`，按 `has_more` 翻页，最多 5 页。
   - 解析 `data[].id`：去掉不合法的名字（只接受字母、数字和 `. _ : / @ + -`），去重，最多 500 个，按名称排序。
   - 失败时分类说明：密钥无效、没有模型列表接口、被限流、返回为空、格式无法识别、连不上（附原因）、服务返回跳转。每种情况都提示可以手动填写模型名称。
   - 只请求供应商自己的地址，不跟随跳转。
   - “测试连接”和终端刷新都改用这个函数。“测试连接”的结果含义不变，成功时多显示取到几个模型。
2. **两个新接口**：
   - `ProviderModels(id, refresh)`：用于已保存的供应商；
   - `PreviewProviderModels(request)`：用于保存之前，可以用表单里填的 key、预设里的钥匙串条目，或者编辑时已保存的 key。预设的钥匙串条目只发往预设的地址；表单里填的 key 只用这一次，不保存也不缓存。
3. **缓存 20 分钟**：
   - 只缓存成功的结果。缓存键是“地址 + 协议 + 认证方式 + 钥匙串条目”，不含 key 本身。
   - 保存或删除供应商时，清掉用到它的钥匙串条目的缓存。
   - 终端刷新和“测试连接”都会更新这份缓存。
4. **供应商表单**：
   - 模型一栏改成可以搜索的下拉，也可以直接填写，旁边有“获取模型列表”按钮。
   - 地址固定的预设，填好 key（或选用钥匙串里的条目）后自动获取。自定义地址要用户自己点按钮，免得把 key 发给还没填完的域名。
   - 编辑已有供应商时，先显示缓存的列表。
5. **终端**：
   - 模型输入框换成同一个下拉，打开会话时带回缓存的列表，刷新按钮更新同一份缓存。
   - 换成供应商单价所配模型以外的模型时，提示“用量照常统计，但不估算费用”。

## 自动测试

- `internal/service`：
  - OpenAI 格式：过滤不合法和重复的名字、请求头带 key、第二次读缓存、刷新重新请求、保存供应商后缓存失效；
  - Anthropic 格式：带 `limit` 翻页，带 `x-api-key` 和 `anthropic-version`；
  - 401、404、空列表、格式错误、跳转：都有对应说明，失败结果不缓存，跳转不跟随；
  - 保存前获取：用表单里的 key；预设的钥匙串条目不会发往别的地址，那次请求根本没有发出；没有 key 时提示先填。
- 原有的“测试连接”测试（不跟随跳转、预设 key 不发往别的地址、结果分类）照常通过。
- 前端：模型筛选（开头匹配优先、完整名字时列出全部）。
- `make check`、`make test`（含竞态检查）、前端 `node --test` 都通过。

## 真机验证（2026-10-30）

- **真实供应商**：用本机已配置的四个供应商走 `ProviderModels`：
  - 七牛 xapi：取到 5 个模型（gpt-5.6-sol、gpt-5.6-terra、gpt-6-astra、gpt-6-sol、gpt-6.1-sol），第二次读取命中缓存；
  - DeepSeek 的 OpenAI 兼容接口：取到 2 个模型（deepseek-flash、deepseek-v4-pro）；
  - DeepSeek 的 Anthropic 兼容接口：返回 404，提示“服务可达，但不提供模型列表接口，请手动填写模型名称”。
- **界面**（模拟后端）：
  - 选七牛 xapi 预设后填 key，0.7 秒后自动获取一次（连续输入 21 个字符只发一次请求），显示“连接正常，取得 5 个模型”；
  - 在模型栏输入 “terra”，下拉只剩 gpt-5.6-terra，回车选中；
  - 自定义地址：填完地址和 key 不会自动请求，点“获取模型列表”才请求一次。

## 范围与限制

- **终端下拉**：终端里的模型下拉和供应商表单用同一个组件；终端界面只做了代码检查，没在模拟界面里打开会话检查。
- **没有模型列表接口的服务**：例如 DeepSeek 的 Anthropic 兼容接口，只能手动填写模型名称。
- **换模型后不估价**：只给出提示，没有做按模型配置单价。
- **缓存只在内存里**：重新打开应用后，第一次会重新请求。
