# 安全诊断中心排版

[验收记录索引](README.md)

## 问题

沙箱详情“运行状态”页的安全诊断中心排得松散：

- 每张卡片里的“边界说明”标签被网格撑满整行，看起来像一条灰色横杠；
- “MCP 权限”套用了通用的紧凑标题样式，上方空出一大段；
- 卡片里套卡片，边框太重；
- “最近拒绝 N 次”统计的是这个沙箱所有被门卫拦下的请求，却放在 MCP 那一行的最右边。

## 改动

- `health.js`：
  - 标题行放门卫状态，右边放“最近拦截 N 次”；有拦截时点它跳到日志页，并选好“拦截”筛选。
  - 四条隔离边界排成一行浅色卡片，每条配一个图标，去掉重复的“边界说明”标签。
  - MCP 权限改成一张列表：名称、类型、已开放的工具数、授权范围，凭据状态用标签区分（凭据可用 / 需要登录或配置）。
  - 最近一次隔离检查放在最下面一行。
- `sandbox-detail.js`：日志标签接受跳转时带的筛选；从标签栏切换时恢复成“全部”。
- `main.css`：新样式；窗口窄于 1100 像素时边界卡片两列一行，540 像素以下一列。

## 实测

在真实 WebKit（WKWebView）里加载前端和模拟后端（4 条边界、2 个 MCP 服务：一个凭据可用、一个需要登录，最近拦截 217 次，最近一次隔离检查 10 项）：

- 截图确认四张边界卡片排成一行，MCP 列表两行、标签颜色正确，各块之间没有大段空白。
- 真实鼠标点“最近拦截 217 次”：切到“日志”标签，筛选是“拦截”；再从标签栏点“运行状态”和“日志”，筛选恢复成“全部”。
- 页面运行中没有脚本错误；前端 `node --test` 全部通过。
