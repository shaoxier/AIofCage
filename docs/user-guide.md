# 使用指南

[文档目录](README.md) · [从源码安装](../README.md#从源码安装)

## 首次配置

首次启动时可跟随「使用教程」完成环境检查、供应商配置、沙箱创建和首次对话。之后也可从左侧「使用教程」继续或重新学习，已有配置会保留。步骤与进度说明见[新手教程](onboarding.md)。

## 配置供应商

在「模型供应商」中按 Codex、Claude Code 或 DeepSeek Harness 添加接口、模型和 API Key，保存后测试连接。同一智能体可以保存多个供应商，密钥保存在 macOS 钥匙串。

模型一栏可以直接填写，也可以从下拉里选：地址固定的预设填好 API Key 后会自动获取模型列表，自定义地址点右侧按钮获取，不用先保存。有些服务不提供模型列表接口，这时照常手动填写。终端里的模型下拉用的是同一份列表，点刷新会重新获取。

每个沙箱中的智能体独立选择供应商，多个沙箱也可以共用同一配置。更改绑定、接口或模型后，重启沙箱才会应用；更新正在使用的 API Key 前，先停止引用它的沙箱。

## 创建与启动沙箱

点击「创建沙箱」，选择或新建项目。默认是带 Shell 的空白沙箱，可以在创建时勾选智能体并绑定供应商，也可以在创建后通过「添加智能体」增装。

项目位于 `~/CageWorkspace`。选择工作区外的文件夹时，应用会先复制一份，智能体修改的是副本；选择工作区内的项目时，直接使用该目录。智能体可以修改或删除项目文件，请使用版本管理或备份。

启动沙箱后，在详情的「终端」页新建智能体会话或 Shell。首次启动会准备专用虚拟机和镜像，进度与异常可在界面查看。虚拟机资源可在「设置」中调整，保存后下次运行环境启动时应用。

启动沙箱时，列表和详情页会按步骤显示进度和用时；构建镜像时还会显示第几步和最后一行输出。首次启动要创建虚拟机、构建镜像，通常需要几分钟。随时可以点“停止”：构建会立即停下；如果虚拟机正在启动，要等它启动完成才会停，以免损坏虚拟机。停止后会说明沙箱当前的状态。有操作在进行时退出应用，会先询问，确认后等这些操作停完再退出。

## 会话与恢复

智能体会话支持任务输入、模型和思考强度选择；Shell 保留原生终端。图片可粘贴、选择或拖入，具体模型要求与大小限制见[图片附件](terminal-images.md)。

切换页面会保留会话；停止、重建沙箱或退出应用会结束当前运行。应用重开后可在沙箱「终端」页恢复原生会话并继续发送消息，不回填旧消息正文。恢复依赖保留的 Agent home 和一致的供应商绑定，手动关闭会话会移除恢复入口。

智能体版本可在「设置」中检查更新并选择新沙箱的默认版本；已有沙箱在详情的「智能体」页独立更新，保留项目和主目录。

## 用量、费用与诊断

| 页面 | 查看内容 |
| --- | --- |
| 用量 | 请求明细、供应商与模型筛选、输入/输出/缓存 token、费用估算 |
| 运行状态 | Agent、门卫与连接器的状态、资源使用、趋势和异常 |
| 日志 | 脱敏请求事件、拒绝原因与日志缺口；可导出最近的事件快照 |
| 安全诊断 | 项目与网络边界、凭据持有者、MCP 授权和最近隔离检查结果 |

费用按设置的模型单价估算，历史请求保留当时的价格快照；不同币种分别汇总，缺少价格或用量时显示未计价。费用估算不等同供应商账单或余额。

运行中不代表模型可用。会话启动失败时先查看链路诊断，核对供应商绑定、凭据及运行环境；隔离检查的「无法验证」「跳过」也不代表通过。审计不记录请求正文、MCP 参数与结果，不是完整的命令或文件操作历史。

## 工具连接与扩展

沙箱默认不能访问任何下载源。需要装依赖或克隆代码时，在创建沙箱时的「开发环境」里，或在沙箱「概览」的「开发环境」设置里，选择 npm 官方源或国内镜像，以及 GitHub 只读；修改后运行中的沙箱立即生效，已经打开的 shell 要重新打开才会读到新的 npm 源。这些预设只放行下载，不能发布包或推送代码。被拦下的请求会返回说明原因的 403，在「请求日志」里能看到对应记录。

如果修改没能送到运行中的沙箱（例如钥匙串没有给权限，或者沙箱还在用升级前的门卫），为安全起见，这个沙箱会暂停联网，并提示原因（界面上它仍显示“运行中”）。应用会每分钟自动重试一次，原因消失后就恢复；也可以自己重试或重启沙箱。

在「工具连接」中配置 MCP 服务，并在沙箱中选择要启用的服务和允许的工具；取消全部工具会保留服务，但拒绝所有工具调用。远程 HTTP/OAuth MCP 保存或登录后会自动获取工具清单（之后可点“测试连接”刷新），默认只开放服务标注为只读的工具，服务新增的工具需要你勾选后才开放。不需要令牌的公开服务（例如文档检索）在添加自定义 HTTP MCP 时勾选“不需要令牌”。

- [业务案例](demo-cases.md)：使用合成数据体验退款复盘、故障排查和交付风险复核。
- [本机 AI 调用](local-agent-control.md)：让外部 AI 通过 stdio MCP 创建隔离沙箱、执行任务和比较结果。

桌面交互会话使用手动选择的供应商；本机控制任务只有显式配置备用供应商时才启用故障切换。

## 重置运行环境

运行环境异常时，可在沙箱「更多」中重置容器和网络。项目与配置保留，可选择保留 Agent home 中的配置和历史，并在重置后自动重新启动。重置会结束当前会话；不保留 Agent home 时，相应的会话恢复记录也会移除。

详细安全机制和恢复限制见[当前架构](architecture-current.md)，已验证的场景见[验收记录](validation/README.md)。
