# AIofCage 桌面工作区产品规格

[文档目录](README.md) · [功能清单](features.md)

2026-10-24，根据团队最新需求实施；2026-10-25 补充 PR #50—#59 的权限、诊断、重置与恢复范围。桌面交互会话继续手动选择供应商，本机 MCP 控制任务支持显式配置备用供应商。

## 产品目标

用户通过图形界面创建长期保留的沙箱，按需添加 Codex、Claude Code、DeepSeek Harness，为每个沙箱中的智能体独立选择供应商，并查看使用消耗和运行状态。日常操作无需输入 Docker 命令。上游秘密继续由钥匙串、可信代理和连接器管理。

## 对象与规则

- 供应商配置属于某类智能体，包含接口、协议、模型、凭据引用及可选价格。同一智能体可保存多份配置。
- 沙箱默认不安装智能体、不启用额外 MCP；基础系统、项目目录和 Shell 可独立使用。
- 创建时可任选三款智能体，创建后可继续添加。未绑定供应商与未安装是不同状态。
- 供应商选择属于“沙箱 + 智能体”。同一供应商可被多个沙箱使用；选择不影响其他沙箱和宿主工具配置。
- 切换配置保存为待生效选择，在下一次重启沙箱时应用；当前容器和会话保留原配置，界面显示生效时机。更新失败必须显示错误，不能把未应用的配置标为成功。
- 增装先准备镜像，再停止并更新容器；保留项目、持久化主目录和用量。失败保留或恢复原配置，禁止静默清空数据。
- 删除沙箱保留项目目录，明确是否保留智能体主目录；测试资源与用户项目分开。
- 开发环境按沙箱选择：npm 官方源和国内镜像二选一，GitHub 只读可单独开启；只放行匿名下载，不放行发布和推送，运行中修改即时生效。
- MCP 服务按沙箱选择工具，取消全部工具仍保留服务但拒绝所有调用。固定连接器的工具由 AIofCage 定义；远程 HTTP/OAuth MCP 的工具来自服务自己的清单，默认只开放服务标注只读的工具，之后新增的工具默认不开放。
- 重置运行环境保留项目、供应商绑定、MCP 权限、额度及版本配置；按选择保留 Agent home 并重新启动。删除 home 时同时移除已失效的会话恢复记录。
- 应用退出或沙箱停止保留原生会话恢复元数据；恢复要求供应商绑定一致，保留模型与思考强度。界面不恢复旧消息正文，主动关闭会话或删除沙箱会清理恢复记录。

## 页面线框

```text
侧栏：沙箱 / 模型供应商 / 工具连接 / 用量 / 日志 / 设置

沙箱                                     [创建沙箱]
[搜索名称、目录]  [全部 / 运行中 / 已停止]
项目与状态        智能体与供应商摘要        用量        [打开智能体] [更多]

沙箱详情：名称、状态、项目目录                 [启动/停止] [更多]
[概览] [智能体] [终端] [用量] [运行状态] [日志]
概览：项目、已安装智能体、工具连接、安全与诊断
智能体：已安装版本、供应商选择、生效说明、添加智能体
终端：已有会话、新开智能体或 Shell、退出/重开、系统终端
用量：时间范围、供应商/模型、输入/输出/缓存、费用、明细
运行状态：组件、CPU/内存、限制、趋势、异常和更新时间

供应商：按三款智能体分类，新增、编辑、复制、测试、价格和使用范围
```

界面以操作和实际状态为主。原理介绍进入帮助或诊断。状态不可仅靠颜色；表单保留标签，弹窗管理焦点，错误持续可见并提供重试。正常环境提示收拢，异常环境展示可操作的原因。

## 用量与费用

- 记录脱敏的请求标识、沙箱、供应商、模型、时间、结果和用量分项，禁止记录正文、请求头或凭据。
- 请求与流式响应解析后记录一次，重连和重启去重。旧累计保留；没有明细的历史不能补造日期或模型分布。
- 支持今日、近七天、全部及供应商筛选。输入/输出与缓存依协议归一化，避免重复计数。
- 费用按供应商、模型和价格版本估算，支持输入、输出、缓存读取、缓存写入单价及币种。缺价格、缺用量、日志缺口明确显示；不同币种分别汇总。
- 改价不重算已记录的历史费用。估算费用与供应商账单、余额是不同数据。

## 运行状态

- 分别展示 Agent、代理、MCP 连接器；资源汇总覆盖实际组件，限制按组件解释。
- CPU、内存、进程数、网络和磁盘 I/O 来自专用 Docker context。退出码、OOM、重启、启动时间来自容器状态。
- 组件运行不等于服务健康。未配置健康检查如实显示；模型/MCP 只展示最近验证或调用结果，不轮询发送计费请求。
- 采样带时间、有效性和错误；失败不填零。有界趋势记录、采集防重叠与清理。虚拟机资源单独展示。
- 隔离检查展示通过、发现问题、无法验证、跳过；执行失败或 DNS 超时不能证明隔离成功。
- 安全诊断页集中展示门卫、凭据与工具授权；静态安全边界只作说明，最近一次隔离检查在应用重开后不保留。
- 日志页按沙箱导出最近最多 300 条脱敏事件 JSON，保留缺口事件；完整持久日志仍在本机 JSONL 文件。

本机 MCP 的任务对比、备用供应商参数及限制见[本机 AI 调用](local-agent-control.md)，本轮实际通过和跳过项目见[PR 整合验收](validation/2026-10-25-pr-integration.md)。

## 工作区改造验收矩阵

以下是工作区改造的 12 项实施与验收要求，对应交付记录见[桌面工作区验收](../outputs/workspace-acceptance/report.md)。后续专题的结果见[验收记录索引](validation/README.md)。

| 序号 | 任务 | 验收重点 |
| --- | --- | --- |
| 01 | 产品规格与验收矩阵 | 覆盖团队八点目标、对象、流程、数据边界 |
| 02 | 导航与视觉组件 | 紧凑布局、明确操作、窗口适配、可访问交互 |
| 03 | 空白沙箱 | 无智能体创建、启停、Shell、数据保留 |
| 04 | 添加智能体 | 组合安装、进度、失败恢复、持久化数据 |
| 05 | 多供应商与独立绑定 | 相同/不同供应商、兼容协议、生效时机 |
| 06 | 沙箱工作台 | 一键进入、终端保留、状态反馈和恢复 |
| 07 | 用量明细 | 多沙箱、流式、未知用量、去重、重启 |
| 08 | 费用与用量页 | 人工计价、缓存、历史价格、币种和缺失状态 |
| 09 | 运行指标采集 | 全组件、限制、错误、重置、过期样本 |
| 10 | 健康面板 | 趋势、异常、真实数据对照和资源开销 |
| 11 | 安全诊断 | 执行失败、证据不足、跳过和边界说明 |
| 12 | 用户路径与交付 | 构建、后端检查、图形操作、三智能体任务、清理与报告 |

每项独立分支、独立 PR，依赖未合并任务时使用堆叠分支并注明依赖。每项完成相关自测与差异复查后继续；团队最终验收时提供全部 PR、构建产物及验证记录。按仓库约定使用 merge commit 合并，保留开发过程。
