# 功能清单

[文档目录](README.md) · [使用指南](user-guide.md)

本文记录当前实现范围，勾选不表示所有供应商和外部服务均已验证。实测环境、通过项、跳过项和限制见[验收记录](validation/README.md)。

## 新手引导

- [x] 首次启动引导与常驻教程入口，检查依赖与 ARM 架构，支持进度恢复、复用已有配置和跳过对话体验。[教程与验证说明](onboarding.md)
- [x] `make dmg` 生成拖拽安装的 DMG 和 SHA256 校验文件，README 给出下载、核对和首次打开的步骤；只有本机临时签名，未公证，第一次打开需要放行。另一台 Mac 上下载试装还没做。[验收记录](validation/2026-10-30-dmg-release.md)

## 供应商与智能体

- [x] 按三款智能体分类管理多个供应商，支持预设、自定义接口、复制和连接测试。
- [x] 获取模型列表：添加或编辑供应商时不用先保存就能获取，模型栏是可以搜索的下拉，也可以直接填写；终端的模型下拉用同一份缓存。[验收记录](validation/2026-10-30-provider-models.md)
- [x] 预设的钥匙串条目只能发往预设地址，复制供应商时不复制它；连接测试等宿主请求不跟随跳转，读出的 key 用完清零。[验收记录](validation/2026-10-30-gatekeeper-hardening.md)
- [x] 每个沙箱独立绑定供应商；保存的选择与当前生效配置分别记录，重启后应用。
- [x] 检查三款官方 CLI 的更新，选择新沙箱默认版本；已有沙箱独立更新，保留项目和主目录，失败回滚。

## 沙箱与会话

- [x] 默认空白沙箱、可选安装、创建后增装；保留项目和持久化主目录，增装失败尝试恢复原配置。
- [x] 开发环境：创建沙箱或在设置里开放 npm（官方源或国内镜像）和 GitHub 只读；只放行匿名下载，发布、推送和自带凭据的请求被拒绝；运行中修改即时生效。[验收记录](validation/2026-10-30-dev-sources.md)
- [x] 启动沙箱时自动补建缺失的专用 Docker 连接，保留当前默认连接，并校验虚拟机共享边界与连接目标。
- [x] 启动、重置、添加或更新智能体按步骤显示进度和用时（镜像构建显示第几步和最后一行输出），可以停止；虚拟机启动这一段等它完成再停。退出应用前先确认，再停止正在进行的操作，不留下构建进程。项目复制导入的进度和取消还没做。[验收记录](validation/2026-10-30-setup-progress.md)
- [x] 智能体镜像的 Debian 系统依赖使用阿里云镜像源，保留软件包签名校验；同版本镜像构建完成后复用。[下载加速验证](validation/2026-10-25-agent-image-mirror.md)
- [x] 可视化创建、搜索、筛选、启停及重启；内置终端、任务输入和系统终端入口。
- [x] 页面切换保留终端会话；沙箱停止、重建或应用退出时结束会话。
- [x] 智能体结构化会话、单一输入框、模型与思考强度选择；Shell 保留原生终端，统一新建菜单。
- [x] 应用重启后列出可恢复的原生会话；只保存非敏感 session 元数据，主动关闭会话时清理恢复记录。面板只显示真能恢复的会话，恢复前检查沙箱里的原生会话文件，失效的记录自动移除；同名标签按序号区分（“Codex 1”“Codex 2”）。[验收记录](validation/2026-10-30-conversation-recovery.md)
- [x] 会话启动失败提供供应商绑定、凭据、门卫、运行环境和会话组件诊断；任务失败按认证、限流、超时和网络错误给出可操作提示，并对诊断尾部脱敏。
- [x] 智能体终端支持图片粘贴、选图、拖入及附件预览；草稿按终端保存。[图片使用说明](terminal-images.md)
- [x] 终端右侧的项目文件栏：只读浏览、文本与图片预览、把路径插入当前对话或 Shell；读取限定在项目目录内（项目被外层沙箱替换成链接或管道也读不到外面、不会卡住），不跟随链接、不读管道和设备，预览一律按纯文本显示。“在访达中打开”改为只显示不打开。“变更”标签和拖入路径还没做。[验收记录](validation/2026-10-31-terminal-files.md)
- [x] 统一 SVG 图标、系统字体与较大控件；窄窗口布局、固定表单操作区和键盘可访问表格。[界面验收](../outputs/ui-polish-acceptance/report.md)
- [x] 支持重置沙箱运行环境：重建 Agent、门卫、连接器和网络，项目与配置保留，可选保留 Agent home，并可在重置后恢复运行。

## 用量与费用

- [x] 持久化请求明细、供应商/模型/时间筛选、输入/输出/缓存 token、未知用量与日志缺口提示。
- [x] 人工填写模型单价，按请求保存历史价格快照；CNY/USD 分开汇总，缺价格或用量时显示未计价。
- [x] 请求额度、token 额度及接近上限提醒；脱敏日志写入本地 JSONL。
- [x] 从公开价格目录查找同名模型、填入参考单价，支持自定义中转价及来源日期；历史费用保留当时快照。

## 运行状态与诊断

- [x] Agent、门卫和 MCP 连接器的状态、CPU、内存、进程数、限制、OOM、退出与重启信息。
- [x] 有界的 CPU/内存趋势、累计网络和磁盘 I/O、采样时间及失败提示；单独展示专用 VM 的配置。
- [x] 隔离检查区分“通过、发现问题、无法验证、跳过”，保留具体证据；泄露比对包含供应商 key、MCP 令牌、OAuth 访问与刷新令牌、门卫管理 token 和连接器 token。
- [x] 隔离检查补上 DNS 外传、Docker 接口、项目边界和绕过网关直连远程 MCP。前三项由宿主临时起金丝雀、对照容器或并列的测试目录作为正向对照，对照不成立就判“无法验证”；运行状态页按状态分别计数。[验收记录](validation/2026-10-31-isolation-checks.md)
- [x] 门卫拦截时返回看得懂的 403：状态行写明沙箱策略，正文用中英文说明原因并附日志编号；安全的下载跳转（没注入密钥、目标在允许范围内）交给客户端重新请求，其余跳转拒绝并记下目标域名。[验收记录](validation/2026-10-30-dev-sources.md)
- [x] 门卫返回上游错误正文前先解码再脱敏，遮盖完整 key、“`...` 加后四位”和 key 的 SHA-256，无法解码的正文整段替换。[验收记录](validation/2026-10-30-gatekeeper-hardening.md)
- [x] 安全诊断中心集中展示项目、网络、凭据、审计边界、门卫状态、MCP 工具授权和最近拒绝记录，并保留最近一次隔离检查结果。
- [x] 基于脱敏请求元数据的 AI 解说，独立于授权和拦截。
- [x] 显示实际虚拟机资源，设置 CPU/内存/磁盘，空闲时可停止运行环境；保存后下次环境启动应用。

## 工具连接与审计

- [x] 审计时间线支持按沙箱查看、筛选和导出脱敏 JSON；导出不包含请求正文、MCP 参数或凭据。
- [x] 停止沙箱或撤销 MCP 服务时先清空门卫授权、删除可信连接器并清理运行期连接器令牌；项目和 Agent home 保留。
- [x] HTTP Token、OAuth、无需令牌的公开 HTTP、filesystem 和 PostgreSQL MCP 接入路径；上游秘密由宿主、门卫或可信连接器持有。
- [x] 沙箱级 MCP 工具权限：固定连接器可按工具授予、撤销，显式空列表表示服务启用但所有工具均拒绝；旧沙箱继续使用连接器目录默认工具。
- [x] 远程 HTTP/OAuth MCP 也只经门卫 MCP 入口访问并按工具授权：宿主获取工具清单，默认只开放服务标注只读的工具，之后新增的工具默认不开放；门卫加令牌、过滤工具列表，拒绝重复键和大小写变体等歧义消息。[验收记录](validation/2026-10-30-remote-mcp-gateway.md)
- [x] PostgreSQL MCP 强制专用只读账号，服务端校验查询结构，拒绝文件读取、程序执行、多语句及事务控制。
- [x] OAuth 账号连接、刷新、过期提示和本机断开授权；第三方 MCP 兼容性矩阵仍需按服务逐项验证。

## 业务案例与本机 AI 调用

- [x] 三个可创建的 MCP 业务案例：渠道退款复盘、发布故障排查、交付风险复核；DeepSeek Harness 使用官方 MCP 插件。[录屏说明](demo-cases.md)
- [x] 本机 stdio MCP：外部 AI 可按供应商创建隔离沙箱、并发执行任务、查结果/用量、取消并比较多 Agent 任务；按控制会话限定操作范围。[调用说明](local-agent-control.md)
- [x] 本机控制任务支持显式候选供应商链，在认证、限流、超时或网络失败时记录原因并切换；桌面交互会话仍由用户手动选择供应商。

## 尚未支持

- [ ] 桌面交互会话的供应商自动故障切换，当前使用手动选择。
- [ ] 供应商账单、余额和真实结算同步，当前费用为按所填单价计算的估算。

其他边界：结构化会话恢复不回填旧消息正文；远程 MCP 只支持 streamable HTTP，不开放资源、提示词和服务端推送；隔离探针只说明已测路径。详见[当前架构](architecture-current.md#当前限制与后续方向)。
